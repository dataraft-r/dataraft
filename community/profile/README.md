# DataRaft

R-native contracts, quality checks and reproducible reports for repeated data
deliveries. Keep business logic in R and publish checked results to files,
databases or an open lakehouse.

The family has seven packages: dataraft (the entry point), core, adapters, lake,
metrics, dbt and catalog. Start with [the project](https://github.com/dataraft-r/dataraft)
and its guarantees, cheatsheet and roadmap. Frozen reports retain input versions
and quality evidence so a historical number can be explained later.

Experimental software maintained by Jan-Hendrik Weinert. Contributions and
prospective maintainers are welcome; there is no production support SLA.
